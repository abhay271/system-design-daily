# System Design Daily

One classic junior-level system design interview question a day, walked through in the same seven steps: functional requirements, non-functional requirements, core entities, API, high-level design, deep dives and interview tips.

Live site: https://abhay271.github.io/system-design-daily/

A scheduled Claude Code routine adds a new entry to `index.html` every morning (06:37 IST) following [`CLAUDE.md`](CLAUDE.md), validates it with `python scripts/validate.py`, and pushes to `main`.
